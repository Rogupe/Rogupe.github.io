What data is processed

Technical data at the hosting provider. The site is hosted on GitHub Pages (GitHub, Inc., USA). Like any web server, GitHub's servers receive your IP address, browser type, the page requested and the time of the request. GitHub states that the IP address of every visitor to a GitHub Pages site is logged and stored for security purposes (GitHub Pages data collection, GitHub Privacy Statement). I have no access to those logs and no analytics are configured.

Images and videos. Photos and videos are loaded from Wix's content delivery network (static.wixstatic.com and video.wixstatic.com, operated by Wix.com Ltd. — Wix Privacy Policy). Your browser sends the same technical data to Wix when it fetches media. The site is configured not to send a referrer, so Wix does not learn which page you were viewing. If the Wix network refuses an image, the page retries it once through images.weserv.nl, an open-source image proxy; that request likewise carries your IP address.

Email. If you write to me, I receive your email address, your name if you include it, and your message in my Google Gmail account (Google Privacy Policy). I use them only to reply and to continue the conversation, I do not share them with anyone else, and I delete correspondence once it is no longer relevant.

Nothing else is collected. There are no contact forms, comments, newsletters, user accounts or payments.

Cookies and similar technologies

This site sets no cookies and does not use localStorage, sessionStorage or any comparable browser storage, for any purpose. No consent banner is shown because there is nothing to consent to. External sites reached through links (LinkedIn, GitHub) apply their own cookie policies.

Analytics, advertising and embeds

None. There is no analytics service, no advertising, no social-media plugin or share button, no embedded third-party player (YouTube, Vimeo, etc.), no external web fonts and no tracking pixel. All videos are my own files, served as plain video files from the Wix network described above.
